## Known limitations

- **Currency rate refresh can lag by hours.** `data/rates.json` is refreshed by a GitHub Actions scheduled workflow (`update-rates.yml`). GitHub's own `schedule:` trigger has had an ongoing, platform-wide reliability problem since around August 2026 — confirmed by GitHub staff on the GitHub Community forum — where scheduled workflow runs get delayed by hours or dropped outright, independent of how the cron expression is written. The site's currency-conversion UI always stays functional (it just reads whatever's currently in the static rates file), but the "last updated" timestamp can occasionally be much older than the configured schedule suggests. A hard fix means triggering the refresh from outside GitHub's own scheduler (e.g. an external cron service calling `workflow_dispatch`) — tracked separately as an "Outside-trigger" backlog item, since it needs new external infrastructure rather than a code change.
- **Brief redraw lag during an especially fast/violent scroll gesture, on mobile (both Firefox and Chrome).** The starfield's parallax/twinkle redraw runs in JS, throttled to roughly 60 redraws/sec — generally very smooth, but an extreme flick-scroll can momentarily outrun it. Considered a reasonable limit of this approach, not planned for further work.
- **A bright star can land directly behind or between letters, hurting text legibility.** Card backgrounds were darkened in v1.2.0 (hero quote, skill/project/pricing/contact cards) which helps, but doesn't fully solve it — a translucent card still lets some stars through, and text sitting directly over the starfield (hero title, section headings) has no card background at all. Several CSS-only fixes were tried and discarded: `text-shadow` and `-webkit-text-stroke` only mask the glyph shape itself, never the gaps between letters and words, so a star sitting in a gap still shows through no matter how strong the outline is; a solid background plate behind each line of text fully closes those gaps, but turns every heading/paragraph into a visible box, which changes the site's look more than it's worth. Revisiting this (likely some form of the background-plate approach, tuned to be much less intrusive) is tracked for a future version.
